# Quiz frames · 002

Template + hydration system for hi-fi single-screen HTML. Lofi wires stay inline in [`boards/mixboard.html`](../boards/mixboard.html) until a screen is promoted.

## Surfaces (three tabs)

| Tab | URL | Purpose |
|-----|-----|---------|
| **Flow** | [`boards/mixboard.html`](../boards/mixboard.html) | Full journey, lofi + hi-fi embeds |
| **Templates** | [`gallery.html`](gallery.html) | Tabbed templates, live preview, spacing tuner |
| **Components** | [`components/gallery.html`](components/gallery.html) | Interactive atoms + composites |

See [`docs/atomic-ladder.md`](docs/atomic-ladder.md).

## Layers

| Layer | Path | Purpose |
|-------|------|---------|
| **Component** | `components/<name>/` | Nav, Trustpilot, radio card, CTA, legal, numeric dock |
| **Template** | `templates/<type>/template.html` | Layout, spacing slots, Trustpilot slot. |
| **Spacing** | `templates/<type>/spacing.json` | Per-template gap tokens (ladder sizes between components). |
| **Hydration** | `templates/<type>/hydrations/<name>.json` | Copy + options + chrome state for one screen. |
| **Variant** | `variants/<name>/` | When layout diverges (e.g. legal footer), not just copy. |
| **Built** | `built/s-<id>.html` | Rendered artifact (committed). Mixboard embeds these. |

## Workflow

1. Edit copy → `hydrations/<name>.json`
2. Edit layout for all screens of a type → `templates/<type>/template.html`
3. Edit Framer-linked look (CTA, headline, Trustpilot, legal) → Component Lab → `./scripts/pull-quiz-component.sh <key>` → re-hydrate
4. Edit vertical gaps between components → [`gallery.html`](gallery.html) spacing tuner → **Save spacing** (writes `spacing.json` + re-hydrates)
5. Layout fork for one screen → new folder under `variants/`, point hydration at `variant`
6. Run hydrate manually if needed:

```bash
./scripts/pull-quiz-component.sh trustpilot-row   # after Framer footer embed changes
./scripts/pull-quiz-component.sh legal-fine       # after Framer legal text changes
python3 scripts/hydrate-quiz-frames.py
```

7. Refresh the mixboard or gallery tab in place (`browser_navigate`, `newTab: false`).

## Templates gallery

- **Tabs** at top: one template visible at a time (`radio`, `numeric-input`, …).
- **Live preview** (left): full 390×844 phone. Optional line above: instance title + id.
- **Thumbs** (right): scaled phones only, no labels. Click to swap live preview.
- **Show spacing overlay**: highlights `.spacing-block` gaps; click a gap → ladder dropdown → Apply.
- **Save spacing**: `POST /api/templates/{id}/spacing` on port 8777; updates `spacing.json` and rebuilds all `built/` frames.

Static assets: [`gallery.html`](gallery.html), [`gallery.css`](gallery.css), [`gallery-spacing.js`](gallery-spacing.js). Instance list: [`gallery.manifest.json`](gallery.manifest.json) (regenerated by hydrate).

## Spacing API (port 8777)

Save spacing from the gallery **Save spacing** button hits `POST /api/templates/{id}/spacing`. Requires `preview_quizzes.py` (not plain `http.server`).

After updating `scripts/quiz_frame_spacing.py` or the hydrate script, restart preview so the API picks up new gap ids:

```bash
python3 scripts/preview_quizzes.py ensure --rebind
```

Verify: `curl -s http://127.0.0.1:8777/api/templates/stat-reveal/spacing` should return JSON (not 400/404).
