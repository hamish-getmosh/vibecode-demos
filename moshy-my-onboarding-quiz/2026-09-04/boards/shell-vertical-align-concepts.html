Implementation plan (Framer new-quiz)

1. Bridge field · Add contentAlignMode: "Top" | "Center" | "Bottom" to quizBridge.ts (default Top).

2. Publisher · New hidden code component ContentAlignSelector (copy ControlBarSelector pattern). Property control enum Top / Center / Bottom. Chain-link to native Content align variable on each guts template master.

3. Consumer · Code override withQuizScrollAlign on the Mobile frame scroll area. Subscribes to bridge; sets justifyContent on the scroll flex column. Overflow guard: if scrollHeight > clientHeight, force flex-start.

4. Template masters · Add Option variable + hidden selector to Intro, Radio Question, Loader, Number Input, etc. Set per instance like Control Bar (loader → Center, radio → Top).

5. Docs + tests · Update quiz-guts-slot-templates.md, quiz-layout-rules.md mapping table, smoke fixture for center step.
