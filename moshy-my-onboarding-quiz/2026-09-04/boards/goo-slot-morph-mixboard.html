Hybrid A

Filter always on

Permanent filter: url(#goo) on the pills row. stdDeviation 2.0 / matrix (6, -1) — tuned down hard from Bebber's 10/(19,-9) so it doesn't wipe the semi-transparent done dots. Soft halo bridge during travel, crisp at rest.

Step 1 / 4

Hybrid A v2

Filter always on · matched done dots

Same as Hybrid A. Done dots use opaque light blue (color-mix(accent 38%, ground)) instead of semi-transparent, so the goo alpha threshold doesn't render them smaller than upcoming idle dots.

Step 1 / 4

Hybrid B

Filter always on · rounder

Same approach as A, pushed rounder: stdDeviation 2.6 / matrix (5, -0.6). Bigger halo on travel; rest is a touch softer than A around the idle dots — documented tradeoff.

Hybrid C · recommended

Filter on transition only

.is-morphing toggled on for the 520ms of each click, filter only applies during that window. Rest state is pixel-identical to the no-goo reference; glow only appears while travelling.
